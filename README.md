# BigData-Football-Analysis
# Big Data Football Market Value Prediction using Apache Spark

This project was developed as part of the Big Data course (ICTS 6339) at the Faculty of Information Technology, The Islamic University of Gaza (IUG).

## Project Description
This research investigates football player market value prediction using Apache Spark distributed processing and machine learning models.

## Technologies Used
- Apache Spark
- PySpark
- Python
- Random Forest Regression
- Linear Regression

## Experiments
- Sequential vs Parallel Processing
- Speedup Analysis
- Efficiency Analysis
- Scalability Testing
- Partitioning Strategy Analysis
